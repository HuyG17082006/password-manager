# Validation

## Username
    - Required
    - String
    - 8-50 ký tự
    - Chỉ gồm : a-z, A-Z, 0-9, `_`

## Email
    - Required
    - Theo chuẩn RFC cơ bản

## Password
    - Required
    - 8-64 ký tự
    - 1 ký tự hoa, thường, số, đặc biệt

## UUID
    - uuid v7
    - uuid v4

## Folder Name
    - Required
    - 1-100 ký tự
