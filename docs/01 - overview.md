## Tên dự án : Pasword manager

## Mô tả
    Một hệ thống giúp người dùng có thể quản lý, lưu trữ và phân loại thông tin đăng nhập của nhiều dịch vụ khác nhau một cách tập trung và an toàn

## Mục đích
    Đối với hệ thống :
     + Quản lý tài khoản
     + Bảo vệ dữ liệu
     + Dễ sử dụng
     + Dễ mở rộng
    
    Đối với học tập :
     + Học database design
     + Học Secure
     + Học Authentication
     + Học Encryption
     + Học React
     + Học Node.js

## Chức năng chính
    - Authentication
    - Folder
    - Account
    - OTP
    - Trash
    - Settings

## Công nghệ sử dụng
    - React
    - Node.js + Express
    - MySQL
    - Redis
    - JWT
    - Nodemailer
    
## Phạm vi
    Nền tảng : Web
    Đối tượng : Người dùng cá nhân

## Kiến trúc tổng quan :
    Browser -> React -> Express API -> MySQL
